موقع كيف KEAF Coffee House
==========================
index.html  : كل كود الموقع
images/     : كل الصور (products = الأصناف، categories = أيقونات الأقسام)

طريقة الرفع على GitHub Pages:
1) فك ضغط الملف على جهازك (GitHub لا يفك ملفات zip).
2) أنشئ Repository جديد (Public).
3) Add file > Upload files، ثم اسحب index.html ومجلد images معاً.
4) Commit changes.
5) من Settings > Pages اختر Branch: main والمجلد / (root) ثم Save.
6) بعد دقائق يظهر الرابط: https://اسمك.github.io/اسم-المستودع

مهم: لا تغيّر اسم index.html ولا اسم مجلد images.
